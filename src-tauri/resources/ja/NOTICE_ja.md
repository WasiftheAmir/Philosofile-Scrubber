# Third-Party & Project-Generated Data Notices — Japanese (`ja`)

This directory contains Japanese morphological dictionary data (IPADIC) and Japanese name/surname lists loaded at runtime by Philosofile's PII scrubber.

## 1. Native Script Name & Surname Lists (`ja_names.txt`, `ja_surnames.txt`)

- **Source:** Wikidata (`ja_names_joined.tsv` for given names; `a7955fa3-query_4.csv` / `5c2a814a-1794212598643_query_4.csv` for surnames).
- **Version / Date:** `2026-11-07` / `2026-11-09`
- **Licence:** **CC0 1.0 Universal** (Wikidata structured data) — https://creativecommons.org/publicdomain/zero/1.0/

## 2. Romanized Given Names (`ja_given_romanized.txt`, `3,983` entries)

This file combines upstream Wikidata data with project-generated expansions:

- **Wikidata base (`CC0 1.0`, https://creativecommons.org/publicdomain/zero/1.0/):** Romanized `en` values extracted from Wikidata (`ja_names_joined.tsv`, `2026-11-07`).
- **Project-generated expansions (CC BY 4.0):** Where Wikidata lacked a Latin `en` label, up to `30` Hepburn and passport long-vowel romanization variants (before deduplication) were generated by Philosofile from `21` Wikidata `kana` entries (e.g., `ou`/`oo`/`oh`/`o` variants via `generate_ja_lists.py`). Only the Wikidata-derived portion is `CC0 1.0`; the project-generated expansions are original repository output licensed under **CC BY 4.0** (`https://creativecommons.org/licenses/by/4.0/`).

## 3. Romanized Surnames (`ja_surnames_romanized.txt`, `13,126` entries)

This file likewise combines upstream Wikidata data with project-generated expansions:

- **Wikidata base (`CC0 1.0`, https://creativecommons.org/publicdomain/zero/1.0/):** Romanized `en` surname values extracted from Wikidata (`5c2a814a-1794212598643_query_4.csv`, `2026-11-09`).
- **Project-generated expansions (CC BY 4.0):** ASCII alias forms generated by Philosofile by stripping Latin macrons/diacritics (`ā→a`, `ē→e`, `ī→i`, `ō→o`, `ū→u`) and apostrophes from non-ASCII entries. Only the Wikidata-derived portion is `CC0 1.0`; the project-generated alias expansions are original repository output licensed under **CC BY 4.0** (`https://creativecommons.org/licenses/by/4.0/`).
